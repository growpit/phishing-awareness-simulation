Security Alert Simulation

This is a cybersecurity awareness exercise. Imagine receiving an unexpected account security warning asking you to take immediate action.

How to identify phishing:

  • Unexpected security alerts.
  • Messages creating urgency or fear.
  • Suspicious sender addresses.
  • Unknown or misleading links.
  • Requests for passwords or personal details.

Remember: Never enter your password through an unexpected link.
