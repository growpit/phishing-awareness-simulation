# Post-Incident Report

## Incident ID
INC-001

## Incident Summary
A simulated phishing attempt was identified
during the security awareness exercise.

## Root Cause
The simulated message used urgency and a
suspicious link to encourage unsafe user actions.

## Response Summary
- Detection: Phishing indicators identified.
- Containment: Simulated threat isolated.
- Eradication: Unsafe elements reviewed.
- Recovery: Training webpage restored.

## Impact Assessment
No real users, accounts, or credentials
were affected.

## Lessons Learned
1. Verify the sender before trusting messages.
2. Avoid clicking unexpected links.
3. Never share passwords through email links.
4. Report suspicious messages promptly.

## Final Status
Closed — Simulation completed successfully.
