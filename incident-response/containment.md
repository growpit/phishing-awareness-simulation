# Incident Containment Report

## Incident ID
INC-001

## Objective
Prevent further exposure from the simulated phishing attempt.

## Containment Actions
1. Mark the suspicious message as phishing.
2. Avoid opening suspicious links.
3. Isolate the simulation from external networks.
4. Notify the security team.
5. Preserve incident evidence for investigation.

## Result
The simulated threat was contained within
the controlled training environment.

## Safety
No real accounts or credentials were involved.
