# Security Awareness Phishing Simulation

## 1. Project Overview
This project demonstrates a phishing awareness
simulation to educate users about common phishing
techniques and warning signs.

## 2. Objectives
- Understand common phishing techniques.
- Identify suspicious messages.
- Educate users about phishing indicators.
- Promote safe online practices.

## 3. Scope
This project uses a local educational webpage.
No real credentials or personal information
are collected.

## 4. Tools Used
- Kali Linux
- HTML
- CSS
- JavaScript
- Python HTTP Server
- VirtualBox

## 5. Implementation
A local webpage displays a simulated security
alert and explains common phishing warning signs.

## 6. Expected Outcome
Users learn to recognize suspicious messages
and avoid unsafe links and credential requests.

## 7. Safety
This simulation is restricted to a local
educational environment.
