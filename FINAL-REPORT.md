# Security Awareness Phishing Simulation
## Capstone Project Report

### 1. Executive Summary
This project demonstrates a local security awareness
simulation designed to teach users how to recognize
common phishing indicators.

### 2. Objectives
- Understand common phishing techniques.
- Identify suspicious messages and links.
- Promote safe email and browsing habits.
- Demonstrate a simulated incident response process.

### 3. Scope
The project operates entirely in a local Kali Linux
environment. No real phishing emails were sent.
No credentials or personal information were collected.

### 4. Tools and Technologies
- Kali Linux
- HTML, CSS and JavaScript
- Python HTTP Server
- Firefox
- Oracle VirtualBox

### 5. Methodology
A local awareness webpage was developed with a
simulated security alert and an interactive button.
Clicking the button reveals common phishing warning
signs and security recommendations.

### 6. Implementation
The webpage was hosted using Python's local HTTP
server and accessed through Firefox at:

http://127.0.0.1:8000

### 7. Testing and Results
The webpage loaded successfully in Firefox.
The interactive button revealed the phishing
warning signs as expected.

### 8. Incident Response
A simulated incident (INC-001) was documented.
The response records cover:
- Detection
- Containment
- Eradication
- Recovery
- Post-incident analysis

### 9. Findings
The simulation demonstrates several common
phishing indicators:
- Unexpected security alerts
- Urgent or threatening language
- Suspicious links
- Requests for sensitive information

### 10. Mitigation Recommendations
- Verify the sender's email address.
- Avoid unexpected links and attachments.
- Never share passwords through email links.
- Report suspicious messages.
- Use multi-factor authentication.

### 11. Conclusion
The project successfully demonstrates a basic
phishing awareness exercise and a documented
simulated incident response workflow.
