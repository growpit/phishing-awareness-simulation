# Project Methodology

## 1. Planning
Selected a Security Awareness Phishing Simulation
to demonstrate how users can identify phishing attempts.

## 2. Scope
The project is restricted to a local training
environment. No real phishing emails are sent.

## 3. Tools Used
- Kali Linux
- HTML
- CSS
- JavaScript
- Python HTTP Server
- Firefox
- VirtualBox

## 4. Implementation
Created a local awareness webpage containing
a simulated security alert and an interactive
button that reveals common phishing indicators.

## 5. Testing
Opened the webpage using Firefox through the
local Python HTTP server and tested its button.

## 6. Incident Response
Documented a simulated phishing incident,
including detection, containment, eradication,
recovery, and post-incident analysis.

## 7. Safety
No real users were targeted and no passwords
or personal information were collected.
